YOUR PASSWORD
IS YOUR FIRST LINE OF DEFENSE.

A strong password is only one part of account security. Combine unique credentials, multi-factor authentication, secure devices, and safe login habits to protect your digital identity.

SCROLL TO EXPLORE
01

STRONG PASSWORDS

Make your passwords difficult to guess and different for every important account.

"DO" This

  • Use long passwords or passphrases
  • Use a different password for every account
  • Use multiple words in a passphrase
  • Use a password manager

DO "NOT" DO This

  • Use your name or birthday
  • Reuse the same password everywhere
  • Use obvious patterns
  • Share your passwords
02

PASSWORD MANAGER

A password manager can securely store your passwords so you don't have to remember every one.

  • Generates strong passwords
  • Stores unique passwords
  • Helps prevent password reuse
  • Makes long passwords easier to manage
03

2FA / MFA

Passwords aren't always enough. Multi-factor authentication adds another verification step.

EXAMPLES

  • Authentication apps
  • Security keys
  • One-time codes
  • Biometric authentication

TIP: Turn on MFA whenever an account supports it.

04

PASSKEYS

Passkeys are a modern way to sign in without relying on traditional passwords.

PASSKEYS CAN USE

  • Fingerprints
  • Face recognition
  • Device PINs
  • Security keys

SECURITY QUESTIONS

Security questions can sometimes be used to recover an account.

BE CAREFUL

Avoid answers that can easily be discovered from social media, public profiles, or basic personal information.

If a service allows it, use a unique answer that isn't publicly connected to you.
